# Miniproject for BIOENG-456: Controlling behavior in animals and robots

Welcome to our Fly Miniproject for BIOENG-456!

Here are the instructions to run our code (same as the one submit by the assistants for the project):


The `run_simulation.ipynb` notebook contains code used to run simulations. 

Replace `<level>` with the desired level number (0 to 4 for the 5 levels) and `<seed>` with the random seed for reproducibility.

In the **Report** folder you can find some successful videos of different levels :

```bash
Level_<level_number>_seed_<seed_number>.mp4
```

The structure of our code in the `controller.py` file is the following :


```bash
    |    Initialisation of our variables
    |    Step fonction with our FSM 
    |    Avoidance Functions
    |    Vision Functions
    |    Wind detection Functions
    v
```
